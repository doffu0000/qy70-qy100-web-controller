Voice Browser

Entries marked QY100 aren't present on the QY70.

To get editable drum sounds, select "Ds1" or "Ds2" as that track's voice in Song mode, or "Ds3" in Pattern mode, directly on the QY100 itself - this can't be selected over MIDI. Once set on the device, use Parameters > Drum Setup below to edit that kit's per-note sound.

    Parameters

    Sent as XG Parameter Change SysEx (F0 43 1n 4C aa aa aa dd..dd F7).

    Click Send XG System On once after connecting (or after any power cycle) before adjusting anything below - the QY100 silently ignores Parameter Change messages until it's been put into XG mode.

    Drum Setup edits whatever kit is currently playing on the Channel selected above, not the kit picker here - that dropdown only picks which note names to display.
