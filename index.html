About editing drum kits

Drum Kit and SFX Kit voices can be edited per-note (including every drum kit element).

Begin by navigating to the Drum Edit screen on the QY70/QY100 - Selecting a drum kit there will automatically update the web console if MIDI is configured.

Ds1/Ds2 (Song mode) and Ds3 (Pattern mode) are separate editable slots that can only be selected on the device itself, not over MIDI - Select one of these on the QY70/QY100, then open its Drum Edit screen before proceeding to edit parameters in the web console.

Note: picking a Drum Kit or SFX Kit voice in the Voice Browser only updates the device while on Ds1/Ds2 - the QY70/QY100 doesn't accept voice selection over MIDI while in Pattern mode (Ds3), so you'll need to match the kit on the device by hand there; the parameter knobs below will still edit correctly once it's matched.

Note: Even elements that look locked on the device's own screen can still be edited from the web console.

Tip: Playing a note on the device automatically will update the web console to display that kit element's editable parameters.

Click a voice, preset, or kit to select it (for editing/saving) - use its Push button to actually apply it.

    Instructions
    
  
    
    
    
    
    
  
    
  
    
    
    
      
    Your browser will prompt for MIDI device access the first time you connect - this page needs that permission allowed, or it can’t see any MIDI interface at all. If you accidentally blocked it, allow MIDI access again from your browser’s site settings (usually the padlock/info icon next to the address bar) and reload the page.
    
      
    Click Find Devices to grant this page MIDI access, then pick your interface from MIDI In and MIDI Out. Leave MIDI In set to (none) for most tasks - incoming messages while an action is in progress can trigger unexpected changes on the device. Turn it on only when editing Drum Setup, where it lets the console follow what you play or select on the device itself.
    
      
    If parameter edits don’t seem to be taking effect, click Send XG System On once - the QY70/QY100 may ignore Parameter Change messages until it receives this. This can also be used to reset all voices to default. Be careful to save your work on the device often to avoid accidental data loss.
    
    
    
    
    
      
    Browse or search every Normal/SFX voice, Drum Kit, and SFX Kit, plus your own saved User Voice/User Kit entries. Clicking a voice, preset, or kit only selects it, for editing or saving - it doesn’t touch the device. Use its Push button to actually send it to the Apply to Part shown above the list.
    
      
    Entries with a QY100 badge aren’t available on the QY70. Voices with a ▸ toggle have saved presets underneath them - full parameter setups you can push the same way. Save/Load Voice and Save/Load Kit write and read your own .qyvoice/.qykit files for reuse later or sharing.
    
    
    
    
    
      
    Pick a section - System, Reverb, Chorus, Variation, Multi Part, or Drum Setup - from the dropdown. Drag a knob or type directly into its value field to edit; Push Parameters sends the section to the device. Each row has an Active/Ignored toggle on the right - Ignored keeps the value tracked and saved, it just stops sending it. Save/Load Parameters captures System, Reverb, Chorus, and Variation together as one .qyparam file.
    
      
    Drum Setup always edits whatever kit is currently playing on the Channel selected at the top, not the kit picker in that section - that dropdown only chooses which note names to display. Ds1/Ds2/Ds3 slots can only be selected on the device itself, never over MIDI - select one there and open its Drum Edit screen before editing it here.
    
    
    
    
    
      
    Shows the last 30 messages sent and received, useful for confirming something actually went out. Toggle it off or clear it from the MIDI Log panel at any time.
