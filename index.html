About editing drum kits

Drum Kit and SFX Kit voices can be edited per-note (including every drum kit element).

Begin by navigating to the Drum Edit screen on the QY70/QY100 - Selecting a drum kit there will automatically update the web console if MIDI is configured.

Ds1/Ds2 (Song mode) and Ds3 (Pattern mode) are separate editable slots that can only be selected on the device itself, not over MIDI - Select one of these on the QY70/QY100, then open its Drum Edit screen before proceeding to edit parameters in the web console.

Note: picking a Drum Kit or SFX Kit voice in the Voice Browser only updates the device while on Ds1/Ds2 - the QY70/QY100 doesn't accept voice selection over MIDI while in Pattern mode (Ds3), so you'll need to match the kit on the device by hand there; the parameter knobs below will still edit correctly once it's matched.

Note: Even elements that look locked on the device's own screen can still be edited from the web console.

Tip: Playing a note on the device automatically will update the web console to display that kit element's editable parameters.

Click a voice, preset, or kit to select it (for editing/saving) - use its Push button to actually apply it.
